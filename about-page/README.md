# About Page

Colby Okazaki's About page, built with React, strict TypeScript and Tailwind CSS (Week 2 deliverable).

## Run it locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

## Scripts

- `npm run dev`: start the dev server
- `npm run typecheck`: check types with `tsc`
- `npm run build`: typecheck, then build for production

## Structure

- `src/pages/About.tsx`: the page
- `src/components/`: Hero, Section, Skills, TechIcon, Projects, ProjectItem
- `src/data/`: skills and projects, mapped into the components
